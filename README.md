Project Data Studio
A portfolio-ready browser app for project managers who need to clean messy project data quickly and turn it into a live dashboard.

What It Does
Paste or upload project data.
Supports comma CSV, semicolon CSV, pipe-separated text, and Excel-style tab paste.
Cleans duplicate rows, messy casing, inconsistent statuses, priorities, dates, and progress values.
Stores cleaned datasets in browser local storage.
Exports cleaned data as CSV.
Builds a live dashboard with:
KPI cards
status mix
clickable status filtering
project filter
priority mix
owner workload
risk signals
