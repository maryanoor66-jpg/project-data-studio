Project Data Studio
Project Data Studio is a browser-based data cleaning and live dashboard app built for project managers. It helps turn messy project task data into clean, structured records and instantly visualizes project health, workload, risks, and progress.

Why I Built This
Project managers often receive task data from spreadsheets, emails, exports, and shared trackers. That data is usually inconsistent: duplicate rows, mixed date formats, unclear statuses, inconsistent priorities, and messy owner names.

This app solves that problem by giving project managers a quick way to clean the data and immediately understand what is happening across their projects.

Key Features
Paste or upload messy project data.
Supports CSV, semicolon-separated, pipe-separated, and Excel-style tab-pasted data.
Automatically removes duplicate tasks.
Normalizes messy statuses such as wip, waiting, completed, and at risk.
Normalizes priorities such as urgent, h, HIGH, med, and low.
Standardizes dates into a clean format.
Cleans project, task, and owner names.
Stores cleaned datasets in browser local storage.
Exports cleaned data as a CSV file.
Builds a live dashboard immediately after cleaning.
Live Dashboard
The dashboard updates directly from the cleaned dataset and includes:

Total task count
At-risk task count
Average progress
Data quality score
Project filter
Status filter
Clickable status chart
Priority mix
Owner workload
Risk signals
Project health overview
Searchable clean records table
How It Works
Paste messy project data into the input box.
Click Clean Data Now.
Review the cleaned preview and cleanup summary.
Use the live dashboard to filter projects, inspect risk, and track progress.
Save the dataset locally or export the cleaned CSV.
In the end you will find your result.
